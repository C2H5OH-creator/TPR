# TPR

## Задача 1

В `lab1` реализована задача оптимизации заказов станков по месяцам. Требуется подобрать план поставок, который минимизирует суммарные затраты на рейсы, доставку станков и хранение остатков на складе, при ограничениях на вместимость склада, объём поставки за месяц и отсутствии дефицита.

Решение выполнено двумя способами:
- [lab1.cpp](/home/c2h5oh/dev/projects/TPR/lab1/lab1.cpp) — реализация на C++ с рекурсией, динамическим программированием и переключаемой мемоизацией
- [lab1.py](/home/c2h5oh/dev/projects/TPR/lab1/lab1.py) — эквивалентная реализация на Python

Поддерживаются четыре подзадачи:
- поиск оптимального плана заказов
- поиск диапазона изменения стоимости хранения
- поиск диапазона изменения постоянных затрат на рейс
- поиск оптимального плана при фиксированном конечном остатке на складе

Запуск:

```bash
./lab1 --memo
./lab1 --no-memo
python3 lab1/lab1.py --memo
python3 lab1/lab1.py --no-memo
```
